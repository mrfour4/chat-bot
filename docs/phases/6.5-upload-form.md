# 6.5 — Upload form

## What you reported

> When a user selects a file that is too large and the Upload button is disabled,
> there should be a tooltip explaining why.
> There should be an X / clear icon so users can remove selected files.
> When no file is selected and the user clicks Upload, the layout collapses. The
> Upload button should be disabled when no file is selected.
> After a file has been successfully uploaded, it should be removed from the list.

## The native input had to go

A `<input type="file" multiple>` shows "3 files selected" and offers no way to
remove one. You can clear the whole control, and only by resetting its `value`.
So the control is now hidden and driven by a button, and the selection is
rendered from form state: one row per file with its size and its own X, plus
"clear all". Removing the last one resets the input's `value`, or re-picking the
same file would fire no `change` event.

## Why the button is disabled

`canSubmit` starts `true` in TanStack Form until validation has run, which is why
clicking Upload with nothing selected produced a validation error and shifted the
layout instead of doing nothing. The button is now disabled from the selection
itself.

The reason is computed rather than read from the form's error list: a Zod issue
on `files[2]` maps to that element, not to the `files` field, so a single
oversized file among several would have disabled the button with nothing on the
field to explain it. `describeRefusal` walks the files and returns the first
real reason, naming the file:

```ts
{ key: "fileTooLarge", values: { name: "de-an-tuyen-sinh-2026.pdf" } }
```

That string is the tooltip, and it is the same catalogue entry the field error
uses, so the two cannot drift apart.

## The tooltip on a disabled button

A disabled button dispatches no pointer events, so a tooltip attached to one
never opens. The trigger is the wrapper instead, and the disabled button inside
it is `pointer-events-none` so nothing swallows the hover. Base UI needs a
`TooltipProvider` above it, which now sits in `AppProviders`.

## Verify

- Nothing selected: Upload is disabled, and hovering it says to choose a PDF.
- Select a file over 20 MB: disabled, and the tooltip names that file.
- Select three, remove the middle one with its X: the other two remain.
- Upload successfully: the list empties.
