# 6.7 — Search

## What you reported

> The search bar should have an X / clear icon. (Both pages.)
> When a search request is in progress, show a loading indicator.
> When the page is initially loading data, show a proper loading state instead of
> the empty state. The empty state should only be displayed after loading has
> completed and there is actually no data.
> If a search returns nothing and you then select all and delete, the UI briefly
> switches to the empty state and back.

## The empty state was lying twice

**On first load.** `loading` was `isPlaceholderData`, which is only true when
React Query is showing a *previous* result. On the very first fetch there is no
previous result, so `loading` was `false`, `documents` was `[]`, and the table
rendered "no documents yet" while the request was still in flight. It is now
`isPending`, which is what "we have never had data" means, and a separate
`refreshing` covers "we have data and are fetching again".

**On clearing a search.** The query is keyed on the *debounced* term, so for
300 ms after you empty the box the app is still showing the results for the old
one — the "nothing matched" state. Then the key changes and the previous page
returns. Nothing was broken; the UI was just honestly reporting a state you had
already left.

So the flicker is fixed at the source: while `search !== debouncedSearch` the
input is *settling*, and a settling search never shows an empty state. It shows
the spinner in the search box, and keeps whatever rows are on screen.

That also makes the two reports one fix. "Show a loading indicator while
searching" and "stop flickering the empty state" are the same missing state.

## The clear button

`InputGroupAddon align="inline-end"` with a button, rendered only when there is
something to clear, and it returns focus to the input — clearing a search box
and losing your place in the page is worse than not having the button.

`SearchInput` is shared by both pages rather than duplicated: same placeholder
mechanics, same clear button, same spinner, same aria wiring.

## Verify

- Reload Documents on a slow connection: skeleton rows, never "no documents yet".
- Type a term that matches nothing, then select-all and delete: no flash of the
  empty state on the way back.
- The spinner appears while typing and goes when results land.
- The X clears the box and leaves the cursor in it.
