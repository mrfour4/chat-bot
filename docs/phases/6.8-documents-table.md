# 6.8 — Documents table

## What you reported

> A document name can be the original file name — very long, with no whitespace.
> Currently a long filename can break the table layout.
> The document reference UI does not provide much value by displaying both the
> file name and file size. Show only the file size.
> When the user clicks on a document, it should open in a new browser tab.
> Add a Download option to the document action dropdown.

## Long names

`truncate` was already on the cell, and did nothing. `text-overflow` only applies
to a box that is actually too narrow, and a table cell is not: `table-layout:
auto` grows the column to fit its widest content, so a 120-character filename
widened the column and pushed the table sideways instead of being clipped.

Three things together fix it, and all three are needed:

- `table-fixed` with explicit column widths, so the columns stop negotiating
  with the content.
- `max-w-0` on the name cell — the idiom that makes a `table-fixed` cell a real
  block box that `truncate` can clip.
- `break-all` on the wrapped title in the rename dialog and the tooltip, because
  a name with no whitespace has nowhere to wrap.

The full name is not lost: it is the link's `title`, so hovering shows it.

## Size only

The second line under the name showed `de-an-tuyen-sinh-2026.pdf · 2.4 MB`, and
the first line was already that name. It now shows the size alone.

## Opening

The name is a link to `/api/documents/{id}/file` with `target="_blank"`, which
serves the PDF through a signed URL. The inline `<iframe>` preview goes with it —
it was 70vh of a table row, and a browser's own PDF viewer in its own tab is
better at this than an iframe is.

That also removes the only place Download lived, which is why it moves into the
actions menu (`?download=1`, which sets the content-disposition on the signed
URL). Deleted and archived rows have no stored file, so the item is hidden rather
than offered and then failing.

## Verify

- A row whose name is 120 characters with no spaces: the column does not grow,
  the name ends in an ellipsis, and hovering shows all of it.
- Clicking a name opens the PDF in a new tab.
- Actions → Download saves the file under its original name.
- Actions on a deleted row: no Download.
