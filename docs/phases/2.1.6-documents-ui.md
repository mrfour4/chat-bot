## The UX consequence of D5 nobody mentioned yet

Indexing is synchronous, so `POST /api/documents` **blocks for 10–15 seconds**.
That is fine for the server and terrible for a teacher staring at a page that
looks frozen.

So the upload control is explicit about what is happening and why it is slow:

```
[ Chọn tệp PDF ]  tuyen-sinh-2026.pdf              [ Tải lên ]
                  ↓ after submit
⠋ Đang tải lên và lập chỉ mục… việc này mất khoảng 10–15 giây.
```

Naming the expected duration turns a hang into a wait. It is one sentence and
it is the difference between the feature feeling broken and feeling careful.

## Structure

The page stays a Server Component for the first render, so the list arrives
with the HTML and RLS scopes it. A single Client Component owns everything that
changes:

```
page.tsx (server)  → requireTeacher, initial listDocuments
  └── documents-panel.tsx (client)
        ├── upload form  → POST /api/documents
        ├── document list + status
        └── polling, only while something is in flight
```

**Polling stops when nothing is `pending` or `indexing`** — using `isPending`
from 2.1.1, which is what it was written for. With synchronous indexing the
poll is usually redundant, and that is the point: it exists for the case where
a request is interrupted after the row is created, which would otherwise leave
the page permanently stale.

## Failure is a first-class state, not an afterthought

Every rejection from 2.1.2/2.1.4/2.1.5 already carries a Vietnamese `message`.
The panel renders those verbatim rather than inventing its own copy:

| Case | Shown |
| --- | --- |
| Wrong type / too large / not a PDF | the `message` from `validateUpload` |
| Duplicate (409) | *"Tài liệu này đã được tải lên với tên …"* |
| Index failed | the row's `error_message`, on the row itself |
| Network / 500 | a generic Vietnamese fallback |

A `failed` row shows its reason inline. This matters most for the case 2.1.5
guards: a scanned PDF that yields no text says *"Không đọc được nội dung từ tệp
này"* on the row — the teacher learns their document is unusable at upload
time, instead of a student discovering it as a wrong answer weeks later.

## One pure helper, tested

`formatFileSize(bytes)` — the current page renders `(size / 1024).toFixed(0)`
KB, which shows a 4.1 MB scan as **"4066 KB"**. Tested: bytes, KB, MB, and the
boundary at 1024.
