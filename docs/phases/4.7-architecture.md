# 4.7 — Architecture

**Goal.** Components render. Everything else lives somewhere it can be found by
its kind.

---

## The directories

```
src/
  app/          routes and route handlers only
  components/   one component per file, grouped by feature, each with index.ts
    ui/         shadcn -- left flat, because the CLI writes here
  constants/    values with no behaviour
  hooks/        client state and server interaction
  lib/          business logic, server-side and shared
    api/        typed callers for this app's own HTTP routes
    validation/ Zod schemas shared by form and server
  providers/    React context providers
  types/        shared types
```

## What moved out of components

**Fetching.** Five `fetch` calls with hand-written `response.ok` checks lived
inside two components. They are now `lib/api/documents.ts` and
`lib/api/chat.ts`, over one `expectOk` helper that reads the API's own
Vietnamese message off a failed response — every route answers with
`{ code, message }`, and restating those messages in the client would only
produce a vaguer sentence from further away.

**State.** `useDocuments` and `useChat` hold what was inside `DocumentsPanel`
and `AskBox`. `DocumentsPanel` went from 150 lines to 35; `AskBox` from 160 to
45. Both are now just layout.

Putting the three document mutations, their toasts and the sweeper nudge in one
hook has a second benefit: an inconsistency between them is now visible in one
screen instead of scattered through a render tree.

**Constants.** `SUGGESTED_QUESTIONS` and the poll interval.

**Types.** `ChatMessage`, `ChatRole`, `HistoryTurn`, `ChatResponse` moved from
`components/chat/types.ts` to `types/chat.ts`.

**Providers.** `app/providers.tsx` became `providers/app-providers.tsx`. It is
not a route, so it was not in `app/`.

## Barrels

Each feature folder has an `index.ts`, and `src/app/**` imports through it.

**Files inside a folder still import each other directly.** A barrel that a
folder's own members import from is a cycle waiting to happen, and it makes
every file in the folder a dependency of every other. The barrel is for
consumers.

## Verification

`npm test` 88 · typecheck · lint · build. No behaviour changed in this phase;
what changed is where things are.
