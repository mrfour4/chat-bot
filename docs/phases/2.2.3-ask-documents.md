# 2.2.3 · askDocuments()

**Type:** integration of the three grounding layers · **API calls: 0 to build**
**Depends on:** 2.2.1, 2.2.2 · **Blocks:** 2.3.1

Where §5.7's three layers meet:

1. **Tooling** — only `fileSearch` is offered. `googleSearch` is never added, and a test asserts its absence: web grounding would still produce citations, so the mistake would look correct rather than broken.
2. **System instruction** — Vietnamese, six rules, including what to do when documents only partly answer or contradict each other.
3. **`enforceGrounding`** — the final say, from 2.2.1.

## Decisions

**Citations only accompany an answer we return.** Attaching sources to a refusal
would imply we found something and chose not to say it.

**History is passed but is never a source.** Retrieval runs on every turn, so a
follow-up ("còn chỉ tiêu thì sao?") can resolve its pronouns against the
conversation while its *facts* still come only from documents. An assistant that
could ground an answer in its own earlier answer would compound its own mistakes.

**D7 settled: `gemini-3.6-flash`.** 3.7 is newer but returned 503 for ~75s
straight in 2.1.0 while 3.6 answered first try, and Google's own 404 for the
retired 2.5-flash points at 3.6. Overridable via `GEMINI_MODEL` so a lower-tier
model can absorb testing while quota is short.

**Failures return, they do not throw.** A quota error becomes the readable
Vietnamese message from 2.1.8 with `reason: "error"`, so the chat route never
has to decide what an exception means.

## One test deliberately absent

The API-failure path has no test here. Vitest 4 surfaces anything thrown from a
`vi.fn()` implementation as a test failure **even when the code under test
catches it** — confirmed by throwing a plain object and watching it fail with
`→ undefined`. Covering it would mean enabling `dangerouslyIgnoreUnhandledErrors`
for the whole suite, hiding real unhandled errors everywhere to cover six lines.

Not a gap worth pretending about: `classifyGeminiError` is tested directly
against real 429 and 503 payloads, and the path already ran in production during
2.1.6, where a live 429 produced the expected Vietnamese message.
