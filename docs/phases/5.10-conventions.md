# 5.10 — Conventions brought up to date

**Goal.** The comments Phase 5 added come out of the source; what they knew goes
into `CONVENTION.md`.

---

## 1. The same rule as 4.9, applied to new code

Phase 5 added about fifty lines of explanatory comment. All of them are gone
from `src/`, removed with the same TypeScript-compiler stripper 4.9 used —
parsed, not matched, because a regex that removes `//` also removes it from
strings, URLs and JSX.

Two comments survive in `src/`, both functional: the two `eslint-disable-next-line`
directives. `"use no memo"` is a directive, not a comment, and stays.

The stripper needed one change: `"use no memo"` had to join the functional list,
or it would have been removed along with the sentence explaining it — silently
re-enabling the compiler on the one component that must not have it.

## 2. Where the knowledge went

`CONVENTION.md` grows from 186 to 262 lines, in four places:

**§2 Components** — which list gets which technique, and why they differ.
Chat's scroller virtualizes by itself; a plain list needs a virtualizer, with
rows measured rather than estimated.

**§6 Data access** — three authorization rules that each came from something
that nearly went wrong: a soft delete is an `UPDATE` and stops being covered by
a `DELETE` policy without failing; `WITH CHECK` cannot say "immutable", so a
trigger must; two permissive policies for one action both run on every row.

**§7 Constraints not visible from the code** — eleven more, including the two
that cost the most time: `signInWithPassword` replaces the token on the client
it is called on, and `realtime.send` swallows its errors as a `WARNING`. Those
two together produced a phase's worth of wrong conclusions in 5.5.

**§8 Background work** — the queue's two-layer sequencing, the
`STALE_AFTER_MS > INDEXING_TIMEOUT_MS` rule, and why the broadcast invalidates
rather than patches.

**§10 Testing** — how to run the integration tests against the mock instead of
spending quota, which is the one operational thing a reader cannot infer.

## 3. What is deliberately not in the source any more

The `.itest.ts` files no longer carry a header explaining how to run them,
matching the files 4.9 stripped. That instruction lives in `CONVENTION.md` §10,
where someone looking for how to run the tests will actually look — rather than
inside a file they would have to already know about.
