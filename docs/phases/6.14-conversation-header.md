# 6.14 — The conversation header

## What you reported

> In the conversation view the title is also too large. Please make it consistent
> with the New Chat title/header layout and sizing.

Same treatment as 6.12: the eyebrow, title and "started on" line move out of the
pinned block and into the top of the scroll region, so they scroll away and the
messages get the height. Both pages now use the same `intro` prop on `AskBox`,
so there is one layout rather than two that resemble each other.

## Two things that block a straight copy

**The "+ Cuộc mới" link is a control, not decoration.** It scrolls away with the
header, which would be wrong if it were the only way to start a conversation. It
is not: the site header's "Hỏi đáp" points at `/`, is always visible, and does
the same thing. The in-page link stays for proximity, and nothing depends on it.

**The intro is hidden while older messages can arrive** — the rule from 6.12,
which exists because anything permanently first inside the scroller stops it
recognising prepends. On the home page that costs nothing. On a long
conversation it means the title is off screen until you page back to the
beginning, so the conversation title now goes into the page metadata:

```ts
const loadConversation = cache(async (id: string) => { … });
```

`cache` dedupes it between `generateMetadata` and the render, so the browser tab
names the conversation without a second query. The tab was previously the
generic "Cuộc hỏi đáp" for every conversation, so this is better than what it
replaces, not just a patch over what it hides.

## A false positive worth keeping

`keys.test.ts` failed on the first version of this page, reporting
`conversation.conversation.metaTitle`. The code was correct — two `t` bindings in
two scopes — but I had written the root one as
`const [t, { id }] = await Promise.all([getTranslations(), params])`, which the
scanner cannot tell from the namespaced one. Two translators called `t` in one
file is confusing for a reader too, so the fix was to stop doing that rather than
to loosen the test.

## Verify

- Open a conversation: the title block scrolls away as you read, the composer
  stays put, and it matches `/`.
- The browser tab shows the conversation's own title.
- Start a new conversation from the header nav while scrolled down.
