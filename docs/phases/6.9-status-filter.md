# 6.9 — Status filter

## What you reported

> The selected option is displayed in Vietnamese in the dropdown, but the value
> shown in the select trigger is displayed in English.

## Why

`Select.Value` resolves its label from the Root's `items`, not from the `SelectItem`
that happens to be selected. From `@base-ui/react/select/value/SelectValue.js`:

```js
children = resolveSelectedLabel(value, items, itemToStringLabel);
```

and in `resolveValueLabel.js`, with no `items` to look in, that falls through to
`String(item.value)`. Our values are `all`, `ready`, `archived`, `failed` — which
are English words, so the trigger looked translated when it was only ever
printing the raw value. It would have shown the same text in any language.

The menu was right because `SelectItem` renders its own children.

## The change

The Root now receives the map it was always asking for:

```tsx
<Select items={statusLabels} ...>
```

built from the same `STATUS_KEYS` the items use, so the trigger and the menu are
now the same strings by construction rather than by coincidence.

## Verify

- Pick "Đã lưu trữ": the trigger reads "Đã lưu trữ", not "archived".
- Switch to English: both change together.
