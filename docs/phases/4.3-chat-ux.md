# 4.3 — Chat UX

Three things from your review, done early because they are things to feel in a
browser rather than read in a diff.

---

## The composer is fixed to the viewport

It was scrolling away with the page. It is now fixed to the bottom, centred,
on a translucent ground with a top rule.

This is the one control on the page, and scrolling up to re-read an answer
should not take it away.

**Two consequences had to be handled, not hoped for:**

**The column would have jumped.** The composer is centred on the *viewport*,
while the home page was a left-aligned `max-w-2xl` column inside a `max-w-5xl`
container — so the input would have sat visibly out of line with the messages
above it. Both chat pages now use `max-w-2xl` as their whole measure, so the
conversation and the input share one column.

**The footer became unreachable.** A fixed bar covers the bottom of the
viewport, and the footer was the last thing in the document — so no amount of
scrolling could bring it out from underneath. Padding around it would only have
hidden the problem.

Instead the disclaimer moved into the composer: *"Trả lời chỉ dựa trên tài liệu
tuyển sinh đã tải lên"*, directly under the input. That is better placement
regardless of the layout — it is a statement about the answers, and it now sits
where the question is asked rather than at the bottom of a page nobody scrolls
to. The global footer is gone.

A spacer clears the bar so the newest message is never left underneath it.

## The document list is gone from the chat screen

The "Tài liệu đang dùng" section is removed. The **count is still read**,
because the empty-library notice depends on it: when nothing is indexed the
assistant correctly refuses everything, and without that notice a correct
refusal is indistinguishable from a broken assistant (§5.12). Saying "no
documents yet" is not the same as listing them.

## Citations are collapsed

`Collapsible`, closed by default, with the trigger reading *"Trích từ N
nguồn"* and a chevron that rotates on `data-panel-open` — the attribute name
read out of the Base UI package rather than guessed.

**The count stays visible when closed.** Collapsing to a bare "Sources" label
would hide whether there were three citations or none, and the whole promise of
this product is that an answer is backed by documents. Closed, it still claims
the evidence; open, it shows it.

## Verification

`npm test` · `npm run typecheck` · `npm run lint` · `npm run build`, then you:
scroll a long conversation and confirm the input stays put, check the column
does not shift, and open a citation.
