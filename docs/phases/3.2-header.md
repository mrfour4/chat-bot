# 3.2 — The header

**Goal.** You asked for the header to be fixed and made consistent. Rather than
restyle it and hope, here is what was actually wrong with
`src/components/site-header.tsx`, and what each fix answers.

---

## What was wrong

1. **No active-page indication.** Three nav links, none of which told you where
   you were. The header was the only navigation in the app and it could not
   answer the first question navigation exists to answer.
2. **Nothing identified the signed-in user, or their role.** A teacher and a
   student saw near-identical headers; the only tell was whether "Tài liệu"
   existed — and you cannot read an absence. The teacher page printed
   *"Đăng nhập với tư cách giáo viên · email"* in its own body, which is the
   right information in the wrong place: true on one page out of four.
3. **"Đăng xuất" was styled exactly like a nav link.** An action that ends your
   session looked like a way to move around.
4. **It could not survive a narrow screen.** Brand, three items and a button in
   a single non-wrapping row, with brand text that does not truncate. At 360px
   the row overflows.
5. **Not sticky.** On the history page — a long list, and the one page you most
   want to leave — navigation scrolls out of reach.

## The fixes

**Active state through `aria-current`, not through colour.** The link for the
current page carries `aria-current="page"`, and the styling is selected *from*
that attribute. One source of truth, and the screen-reader announcement and the
visible state cannot drift apart.

This needs `usePathname`, which needs a client component — so the nav splits
into `site-nav.tsx` (client) while the header shell stays a server component
holding the session. The session never crosses into client state; only the
already-public name and role do.

**Identity moves into the header, where it is true on every page.** Name (or
email) plus a role badge — `Giáo viên` in lacquer, `Học sinh` in soft ink. The
teacher page's own line is removed rather than duplicated.

**A rule separates navigation from account.** "Đăng xuất" sits after a divider
with its own quieter treatment, so it stops reading as a fourth destination.

**Wrapping is real, not hoped for.** The brand truncates; the name hides below
`lg`, leaving the role badge, which is the part that changes what you can do.
`lg` rather than `sm` because a teacher carries the most items — brand, three
links, badge and sign-out — and that is the row that has to fit.

**Sticky, with a translucent ground.** `sticky top-0 z-40` over
`bg-paper/85 backdrop-blur`. The border stays, so the header never floats
ambiguously above content.

## Not done, deliberately

**No hamburger menu.** Three links do not earn a drawer, a toggle, focus
trapping and an escape key. The row fits when the identity text yields.

## Verification

browser: sign in as each role, visit each page, and narrow the window to 320px.
